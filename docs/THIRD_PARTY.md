# Third-party components

## PySide6 / Qt for Python

PySide6 is not included in this source archive.

Reference version used by the source branch:

```text
PySide6 6.11.1
PySide6_Addons 6.11.1
PySide6_Essentials 6.11.1
shiboken6 6.11.1
```

Before producing a reproducible offline deployment:

1. archive exact wheels for every target Python/platform combination;
2. record SHA-256 for every wheel;
3. preserve upstream license notices;
4. test installation without network access;
5. test real rendering under the target desktop session.

PySide6 is offered under open-source and commercial licensing terms. This file
does not provide legal advice and does not replace the upstream license text.
